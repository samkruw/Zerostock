# ZeroStock V3.1 – Carton Fix

Behoben:
- `+ Karton` reagiert zuverlässig.
- Onboarding-Button `Ersten Karton anlegen` nutzt denselben robusten Handler.
- Karton-Dialog wird unabhängig von anderen Renderfunktionen geöffnet.
- Dialogfelder werden vor Zugriff geprüft.
- Speichern zeigt Firebase-/Validierungsfehler sichtbar an.
- Speichern ist nur für Admin vorgesehen.
- Dialog-Schliessen setzt auch Inline-Display sauber zurück.
- Professionelles Logo, Firebase LIVE, Multiuser, QR, TINST, Planner und PWA bleiben erhalten.
