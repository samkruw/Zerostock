# ZeroStock V5.3.3

- Der Bildhintergrund bleibt beim Start ruhig. Die drei Flächen des Z bewegen sich mit kurzen, überlappenden Bewegungen und blenden gemeinsam in die Arbeitsansicht über.
- Die Präsentation läuft beim ersten Öffnen pro Sitzung vollständig durch. Antippen, Escape, Enter und Tab führen keine Aktion hinter dem Startbildschirm aus. Wird die Seite während des Starts neu geladen, beginnt die Präsentation erneut.
- Bei reduzierter Bewegung erscheint das zusammengesetzte Logo für dieselbe Dauer. Ein direkt geöffnetes Regaletikett führt anschließend zum zugehörigen Artikel.
- Die Anmeldung wird auf Website und Android im Hintergrund vorbereitet. Bei Verbindungs- oder Zugriffsproblemen zeigt ZeroStock einen verständlichen Hinweis.
